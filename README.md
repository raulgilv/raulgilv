# Raúl Gil Vega

Senior Software Engineer building backend and event-driven systems at scale.
Remote, based in Madrid, España.

Currently working on serverless, event-driven systems on AWS (Lambda, EventBridge, Kinesis), third-party API integrations, and async workflows — with a focus on what happens when these systems actually start failing or scaling for real.

## What I do

- **Event-driven architecture migrations.** Migrated 10+ legacy integrations to an event-driven architecture on AWS using the strangler fig pattern — gradually, without stopping the service — cutting deploy time from ~1hr to under 5 minutes.
- **Infrastructure as code.** Own IaC (AWS CDK) across 100+ services: provisioning, pipelines, and incident response, from spec to production.
- **Observability.** Built end-to-end cross-account event traceability, alarms and circuit breakers (CloudWatch), and dashboards (Grafana) — so failures surface before a customer reports them.
- **Payments.** Integrated Stripe, PayPal, 3DS, and bank payment gateways — an area where edge cases matter and small mistakes have real consequences.
