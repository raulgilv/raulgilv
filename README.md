# Raúl Gil Vega

Senior Software Engineer. I build backend and event-driven systems at scale.
Remote, based in Madrid, España.

Right now I'm working on serverless, event-driven systems on AWS (Lambda, EventBridge, Kinesis), third-party API integrations, and async workflows. What interests me most is what happens when these systems start failing or scaling for real.

## What I do

- **Event-driven migrations.** Moved 10+ legacy integrations to an event-driven architecture on AWS using the strangler fig pattern. Did it gradually, without stopping the service, and cut deploy time from about an hour to under 5 minutes.
- **Infrastructure as code.** I own IaC (AWS CDK) across 100+ services, from provisioning and pipelines to incident response, taking things from spec to production.
- **Observability.** Built cross-account event traceability end to end, plus alarms and circuit breakers in CloudWatch and dashboards in Grafana. The goal is for failures to surface before a customer reports them.
- **Payments.** Integrated Stripe, PayPal, 3DS, and bank payment gateways. This is an area where edge cases matter a lot and small mistakes have real consequences.
